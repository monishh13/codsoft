Grade Calculator – Java

This is a simple Java console program that calculates the grade of a student based on marks entered for multiple subjects.

What it Does:

Asks how many subjects you have

Takes marks for each subject

Calculates total marks

Finds average percentage

Displays grade based on the percentage

Technologies Used:

Core Java

Scanner for user input

How to Run:

Make sure Java is installed.

Open the program in any IDE or terminal.

Run GradeCalc.java.

Enter number of subjects and marks when asked.

Get your total, percentage, and grade.

Grading Rules:

90 and above → A

75 and above → B

60 and above → C

50 and above → D

Below 50 → F

Notes:

Enter valid numeric marks.

Works entirely offline.
