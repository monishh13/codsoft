Currency Converter – Java

This is a simple Java desktop application developed for currency value conversion using current, real-time exchange rates. It makes use of the Frankfurter API to fetch up-to-the-minute rates, featuring a GUI built in Java Swing.

Features:

Base and target currencies should be selected.

Enter any amount to convert

Retrieves current conversion rate

Displays result instantly

Very simple UI, easy to use

Technologies Applied:

Java

Java Swing (GUI)

Java HTTP Client

Frankfurter Currency API

▶️ How to Run

Install Java (JDK 11 or above).

Open the project in your favorite IDE - IntelliJ / VS Code / NetBeans / Eclipse.

Execute the CurrencyConverter.java file.

Type the amount → choose currencies → click Convert.

Internet Requirement

The application requires an active Internet connection to retrieve current currency exchange rates.
 
Notes:

If it fails, it is usually a problem with the Internet or because some invalid input was entered.

API supports only the popular global currencies.
